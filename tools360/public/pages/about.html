About Tools360

Tools360 is a set of everyday file tools that run entirely in your web browser. You can merge and split PDFs, shrink and convert images, and make QR codes without creating an account.

How it works

When you add a file, your browser does the work using open-source JavaScript libraries. The file is not sent to our servers, which keeps things fast and private.

What we care about

  • Privacy first: no uploads for our core tools.
  • Clear, simple pages with no tricks or hidden buttons.
  • Honest limits: we tell you plainly when a tool cannot do something.
